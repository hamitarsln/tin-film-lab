## Lessons

- Keep: Keep the exact same recognizable asset across file-format changes.
- Try: For Tin export, show one campaign card in source, editable export and reopened state; make file names and one editable headline large.
- Try: For a compact workflow film, turn a real format error into one corrected file and an obvious success state before adding any style montage.
- Avoid: Using a large effect showcase as a substitute for showing preserved editable structure.
- Still open: Conversion fidelity, actual command execution, sound and precise motion remain unverified.
