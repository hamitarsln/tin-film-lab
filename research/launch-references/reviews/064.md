## Lessons

- Keep: Keep the prompt-box shape stable while the reference category changes.
- Try: For Tin research, show one query, three actual reference cards and a single analysis finding using the same screen layout.
- Try: Test one restrained textured background behind large headings, with a plain area reserved for small product text.
- Avoid: Ending on a performance question with no answer after many quick capability claims.
- Still open: Retrieval accuracy, dataset scale, analysis quality, sound and precise transitions remain unverified.
