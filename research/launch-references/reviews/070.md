## Lessons

- Keep: Use a clear visual palette change to mark the move from problem to proposed solution.
- Try: For Tin memory, show one user correction and a later draft that keeps it; use the same phrase and campaign context as proof.
- Try: Build a short growth analogy with one plant image, then shift to a plain UI showing the remembered detail rather than extending the montage.
- Avoid: Claiming continuous learning through imagery without showing a changed model response.
- Still open: Actual learning mechanism, model behavior, sound and exact transition details remain unverified.
