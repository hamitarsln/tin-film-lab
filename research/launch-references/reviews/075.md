# 075 · Flexprice | FinePrint: Benchmark AI Models on Real Contracts

**Explains well:** The later UI shows comparison metrics, a contract-to-score process and a model selector.

**Still unclear:** The first 80 seconds largely delay the benchmark; the shown scores do not establish evaluation quality.

## Lessons

- Keep: Return to the same opening phrase with a more specific product question.
- Try: For a Tin document workflow, show a missed renewal clause, its source line and a corrected extraction side by side.
- Try: Create a 20-second benchmark cut: one contract, two model outputs, one metric row and a clear Run extraction action.
- Avoid: Delaying the actual benchmark behind a long unrelated montage.
- Still open: The black sampled interval, evaluation validity, clip provenance and all audio remain open.
