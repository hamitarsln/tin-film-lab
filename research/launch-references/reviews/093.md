## Lessons

- Keep: Keep the same source object recognizable through generated outputs and revisions.
- Try: For Tin, use one rough product sketch, generated ad draft and a requested color change with the same composition.
- Try: For a coding-agent demo, show one error condition, the debug action and a tested corrected state before the broader gallery.
- Avoid: Treating a rapid gallery as proof of reliable generation.
- Still open: Continuous sketch/world transition, actual build reliability and sound remain unverified.
