## Lessons

- Keep: Use the same detailed poster in both formats so the change is immediately inspectable.
- Try: For Tin, adapt one campaign poster to portrait and landscape while keeping the same headline, date and product image visible.
- Try: Build a short scale-loop opening/ending around one campaign asset, with the actual editor action in the middle.
- Avoid: Letting impressive scale changes replace a full-resolution check of the adapted output.
- Still open: Image fidelity, actual edit behavior, unseen-area generation, sound and precise zoom path remain unverified.
