## Lessons

- Keep: Use a consistent frame and caption system to join many contributor recordings, and retain a clear limit on the promise.
- Try: Replace one repeated interview point with the same transaction shown as an unreadable request and a clear request.
- Try: For Tin, compare an unclear approval request with one showing the exact asset, destination, date and action.
- Avoid: Letting expert testimony and availability labels substitute for a concrete user-facing example.
- Still open: Standard implementation details, adoption coverage, wallet behavior, security outcomes, source identities and audio remain unverified.
