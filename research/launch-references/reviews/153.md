## Lessons

- Keep: Start with a familiar search query before expanding the visibility problem across channels.
- Try: Track the opening CRM query into one problem row, one corrective action and a checked result.
- Try: For Tin, carry one campaign title from performance table through asset revision to channel preview.
- Avoid: Using a recovery slogan as the only bridge between diagnosis and improvement.
- Still open: The improvement action, data coverage, actual gains, asset provenance and audio remain unverified.
