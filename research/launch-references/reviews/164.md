## Lessons

- Keep: Move from a repeated internal component to a clean complete-product reveal.
- Try: Use one maker workload and a labeled measured result to explain the power claim.
- Try: For Tin, connect a brief processing visualization directly to the resulting campaign asset and next action.
- Avoid: Using diagnostic-looking imagery as a substitute for a concrete user benefit.
- Still open: Workload benefit, performance measurements, hardware claims, release status, rendering methods and audio remain unverified.
