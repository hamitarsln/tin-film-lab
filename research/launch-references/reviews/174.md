## Lessons

- Keep: Give different action categories different arrow structures while keeping one mascot.
- Try: For an agent tool, show Connect, one balance request and a returned balance in the same terminal panel.
- Try: Use circular arrows for synchronisation and straight arrows for transfer, then test whether viewers can name the two actions.
- Avoid: Avoid presenting prompt examples as completed product proof.
- Still open: How does the integration request permission and report success or failure?
