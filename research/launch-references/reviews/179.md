## Lessons

- Keep: Carry the same customer context through every generated artifact.
- Try: For a sales assistant, show a call excerpt, the matching proposal paragraph and a confirmed CRM field update.
- Try: Compare a three-panel source/draft/result view with the layered window animation, keeping all text readable.
- Avoid: Avoid treating buttons, animated cursors or large figures as verified execution and savings.
- Still open: Which actions need approval, and how is each generated detail linked to source evidence?
