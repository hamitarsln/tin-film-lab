## Lessons

- Keep: Show action logs next to the interface state that they change.
- Try: For a voice scheduling tool, keep the spoken-request transcript beside a confirmed reminder with a date and time.
- Try: Record the same settings navigation with the face inset below the controls and a tighter application crop.
- Avoid: Avoid using a Sent transcript entry as proof of a completed external task.
- Still open: Was a reminder ultimately scheduled, and which provider controls can voice mode operate?
