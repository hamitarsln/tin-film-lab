## Lessons

- Keep: Use domain-specific objects to make an abstract coordination problem visible.
- Try: For hardware documentation, carry one headset requirement from a paper source into a linked software finding and resolved status.
- Try: Compare the multi-worker room montage with a shorter three-role sequence, using the saved time for a readable document result.
- Avoid: Avoid implying that an agent answer or organised document proves certification.
- Still open: Which requirement sources support the shown verdict, and was a laboratory or certifier involved?
