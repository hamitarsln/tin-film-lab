## Lessons

- Keep: Use a strong destination image to give an abstract aspiration a visual endpoint.
- Try: Add concrete program features or an actual participant-day sequence before Apply now.
- Try: For Tin, follow campaign ambition with the real brief, output and approval step.
- Avoid: Letting an evocative place name substitute for explaining the offer.
- Still open: Program format, actual environment, application details, market claim context, footage origin and audio remain unverified.
