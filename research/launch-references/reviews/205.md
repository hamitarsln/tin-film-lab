# 205 · General Instinct | General Instinct: Deploying Frontier AI Models on Edge Hardware

**Product from the film:** General Instinct prepares AI models and software stacks for small edge devices.

**Explains well:** The held circuit board and large-versus-small memory diagrams explain why cloud-sized models are hard to run on a device.

**Still unclear:** The film jumps from hardware constraints to a working robot without showing model preparation, deployment or a measured result on the stated chip.

## Lessons

- Keep: Make a hardware constraint tangible with a held object and a simple memory comparison.
- Try: Show one model entering the pipeline, its prepared package and the exact target board beside the running robot.
- Try: Add a before-and-after memory and latency comparison using the same task and device.
- Avoid: Avoid using a working robot alone to explain an unseen deployment workflow.
- Still open: What does the user supply, what package is returned, and which measured change makes it fit?
