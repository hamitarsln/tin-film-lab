# 216 · Clicky | Clicky: Simplest Interface to Spawn Agents

**Product from the film:** Clicky is a Mac desktop companion beside the cursor that can receive spoken tasks and run several agents.

**Explains well:** Colour choices, cursor companions and task status cards give the agent a small, personal presence on the desktop.

**Still unclear:** The demo changes tasks before showing a clear request, completed result and user response for any one of them.

## Lessons

- Keep: Give an assistant a small, consistent place and colour on the user’s desktop.
- Try: Show the resume request, the changed paragraph and a completion card in one continuous example.
- Try: Compare two agents with distinct colour labels and show which finished file belongs to each.
- Avoid: Avoid using several progress cards as the only demonstration of useful work.
- Still open: What did Clicky change, and how does the user inspect or accept the result?
