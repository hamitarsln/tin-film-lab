## Lessons

- Keep: Use specific visual feedback so viewers can judge whether the result answers the request.
- Try: Keep the same image while changing only colour and type, then highlight the two requested differences.
- Try: Show a reference image beside the generated page and label which visual traits were carried across.
- Avoid: Avoid changing unrelated assets in a focused-edit demonstration without explaining why.
- Still open: Can the user preserve chosen images and layout while applying only selected comments?
