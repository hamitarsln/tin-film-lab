## Lessons

- Keep: Keep one input surface fixed while changing the user context.
- Try: Show a Tin request from a cafe, then its approved campaign result using the same title.
- Try: Compare a request-only cut with a request, permission and receipt cut to test whether viewers understand the agent role.
- Avoid: Avoid using a closing action claim as the only evidence of completion.
- Still open: Exact composer text, task completion, settlement mechanism, permissions and all audio remain unverified.
