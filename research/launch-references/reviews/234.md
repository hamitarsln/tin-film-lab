# 234 · Vori | Vori raises $22M Series B to make supermarkets autonomous

**Product from the film:** Vori combines grocery records, automated store actions and payments, presented as an operating system for a self-driving supermarket.

**Explains well:** The miniature store makes inventory gaps, wrong prices and paperwork visible, then revisits them with three clearly numbered systems.

**Still unclear:** The model explains the idea well but does not show the actual software controls, exceptions or staff role behind automatic ordering and price updates.

## Lessons

- Keep: Revisit the same physical examples in the problem and solution sections.
- Try: Link the miniature price update to one actual software control and staff role.
- Try: For Tin, show the same brief, asset and queue before and after an automated action.
- Avoid: Leaving a clear conceptual model disconnected from the actual user controls.
- Still open: Automation boundaries, staff exceptions, real interface, metric accuracy, miniature production method and audio remain unverified.
