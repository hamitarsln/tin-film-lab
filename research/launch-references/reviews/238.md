# 238 · Saperly | Saperly: First Phone Carrier Built for AI Agents

**Product from the film:** Saperly presents a phone carrier and phone identity for AI agents so they can reach services that require calls.

## Lessons

- Keep: Explain infrastructure through an everyday task that fails for one clear reason.
- Try: Show the agent receiving a number, placing the restaurant call and returning a reservation confirmation.
- Try: Add one developer setup step that connects the agent to the phone service before replaying the flower order.
- Avoid: Avoid ending after the capability label when the opening has promised a completed task.
- Still open: How does an agent connect to Saperly and return a useful result from the call?
