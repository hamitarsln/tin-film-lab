# 245 · Saffron | Saffron: Identify Your Next 10x Engineer

**Product from the film:** Saffron assesses engineering candidates using real repositories and AI tools, recording code changes and prompts for an evaluation report.

**Explains well:** The film clearly contrasts conventional interview exercises with work on a real codebase using AI, then outlines repository selection, work and analysis.

**Still unclear:** No specific candidate action is connected to a report finding, so the meaning of the scores and AI-reliance percentage remains vague.

## Lessons

- Keep: State the real-work difference in simple, large comparison text.
- Try: Link one candidate action to its report finding.
- Try: For Tin, show the source detail behind each important quality finding.
- Avoid: Presenting summary percentages as self-explanatory evidence of ability.
- Still open: Assessment meaning, validity, real workflow details, hiring outcomes, source claims and audio remain unverified.
