# 272 · Alt-X | Alt-X: AI Agents for Real Estate Underwriting Models in Excel

**Product from the film:** Alt-X presents an agent that builds real-estate underwriting models in Excel from documents.

**Explains well:** The demonstration connects a PDF upload and explicit build request to populated spreadsheet sections and proposed changes.

**Still unclear:** The source-checking promise is not as clear visually as the generation: the detail card does not clearly take the viewer back to the original source passage.

## Lessons

- Keep: Mirror the manual document-to-sheet task with the agent version.
- Try: For Tin, show the same source information entering a campaign manually and through an agent.
- Try: Keep one source fact visible beside its generated output, then approve a proposed edit and show the changed result.
- Avoid: Avoid using a verification slogan without a readable example of the verification.
- Still open: Source-to-cell mapping, formulas, change application, timing and all heard audio remain unverified.
