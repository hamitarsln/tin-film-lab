## Lessons

- Keep: Keep the repeated Scrape, Search and Browse chapter structure.
- Try: Make the Browse source a founder table and highlight one row becoming the same JSON record.
- Try: Hold the install command and one minimal scrape result long enough to read the URL and two returned fields.
- Avoid: Avoid using unrelated sample data on opposite sides of an extraction transition.
- Still open: Audio is unheard; command behaviour, authentication and result accuracy remain unverified.
