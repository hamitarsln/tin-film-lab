# 308 · Button | Button: Wearable AI That Can Talk

**Product from the film:** Button is a small wearable conversational assistant that people ask for practical help and suggestions.

**Explains well:** A visible press, spoken request shown in captions and a response give the wearable a clear role before its name card appears.

**Still unclear:** Several scenes show questions and witty answers, but activation and ending a session are not equally clear across the examples.

## Lessons

- Keep: Return to the opening character so a montage has an ending.
- Try: Show one complete activation-to-session-end interaction.
- Try: For Tin, repeat one approval action across businesses and return to the first published result.
- Avoid: Presenting staged question/reply scenes as measured product performance.
- Still open: Activation rules, session ending, answer accuracy, sensing, response time and audio qualities remain unverified.
