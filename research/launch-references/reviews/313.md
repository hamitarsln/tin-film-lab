# 313 · Ashr | Ashr: Test agents with synthetic production environments

**Product from the film:** Ashr presents automated testing for AI agents using generated scenarios, an SDK and run summaries.

**Explains well:** The explainer names the inputs needed for tests and distinguishes actual agent behavior from expected behavior.

**Still unclear:** The illustrated setup uses a scheduling agent, but the later examples switch to banking and orders, so no single test is followed from configuration to failure.

## Lessons

- Keep: Compare actual and expected actions, not only the wording of an answer.
- Try: For Tin, show a scheduling task with one deliberately difficult input and the resulting failed step.
- Try: Keep the same task, tools and expected outcome visible from configuration through the report.
- Avoid: Avoid changing domains between the test setup and its supposed results.
- Still open: Live-product fidelity, test coverage, trace details, metrics and all heard audio remain unverified.
