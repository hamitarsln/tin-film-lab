# 321 · SynScience | SynScience Launches AI Co-Scientists for End-to-End Research

**Product from the film:** Synthetic Sciences presents SynSci as a workspace for AI research agents that plan experiments, run model training, write reports and help deploy a model feedback loop.

**Explains well:** The protein-model request stays visible through planning, training logs, a results table and a written report, giving the research promise several concrete artifacts.

**Still unclear:** The deployment section shows API documentation and a feedback diagram, but no actual request, returned prediction and new feedback-triggered training run.

## Lessons

- Keep: Keep the same project visible from request through report.
- Try: Show a prediction request and response followed by feedback changing the training state.
- Try: For Tin, follow one brief through asset, review, publication and feedback.
- Avoid: Using endpoint documentation as the final proof of a live feedback loop.
- Still open: Actual deployment cycle, approval interaction, experimental validity, benchmark claims and audio qualities remain unverified.
