## Lessons

- Keep: Keep the three distinct agent roles and their matching outputs.
- Try: Replace part of the final agent swarm with one weekly-update setup: instructions, source and schedule.
- Try: Show the launch-date answer beside the source page line it uses, so the reply has visible context.
- Avoid: Avoid jumping from New Agent to implied autonomy without showing the basic setup.
- Still open: Audio is unheard. Agent reliability, permissions, trigger behaviour and source accuracy remain unverified.
