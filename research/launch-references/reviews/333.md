# 333 · Polymarket | Introducing Polymarket CLI - fastest way for AI agents to access prediction markets

**Product from the film:** Polymarket CLI provides terminal commands for wallet setup, listing prediction markets and submitting an order.

**Explains well:** The final market-order command returns MATCHED and Success: true, giving this short terminal demo a visible result.

**Still unclear:** The order uses a long token identifier without clearly linking it to one selected market row, so the viewer cannot easily tell which question was bought.

## Lessons

- Keep: Finish a command demo with its explicit returned status.
- Try: Link the chosen market row to the order token and result.
- Try: For Tin, pair a publish command with its post ID, status and preview.
- Avoid: Leaving long identifiers disconnected from the human-readable task.
- Still open: Selected market identity, independent transaction state, execution timing, agent integration and audio qualities remain unverified.
