## Lessons

- Keep: Keep named automation examples and readable crops that connect tools to developer work.
- Try: Carry the amount-of-undefined error through one run to a readable code diff and PR.
- Try: Submit the blog request and show its preview beside the request, shortening the automation-list hold.
- Avoid: Avoid ending both example workflows before the result.
- Still open: Actual audio and product execution are unverified; ASR contains corrupted names and technical phrases.
