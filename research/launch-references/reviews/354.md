# 354 · Tavus | Introducing Phoenix-4: Advanced Real-Time Human Rendering Model

**Product from the film:** Tavus presents Phoenix-4 as a real-time human-rendering model for expressive conversational avatars.

**Explains well:** Emotion labels, face landmarks and example calls give concrete visual anchors to the founder explanation.

**Still unclear:** The long explanation does not show a setup workflow, and the reaction examples lack visible input text or timing markers that would make their context easy to judge.

## Lessons

- Keep: Use short labels and targeted callouts to focus attention on subtle output behavior.
- Try: For Tin, pair one input sentence with a labelled output change and a visible timeline.
- Try: Show one short setup-to-result flow before a longer technical explanation.
- Avoid: Avoid making viewers infer the cause and timing of a reaction from an expressive face alone.
- Still open: Conversational timing, lip sync, comparative fairness, model execution, long-run consistency and all heard audio properties remain unverified.
