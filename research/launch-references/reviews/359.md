# 359 · emdash | Emdash: Open-Source Agentic Development Environment (ADE)

**Product from the film:** Emdash is an open-source environment for running coding agents in separate tasks and reviewing their changes.

**Explains well:** The walkthrough links task creation, agent selection, diffs, pull-request controls and checks inside one interface.

**Still unclear:** The first issue is left running while other tasks demonstrate completion, so its own change and final result are not followed.

## Lessons

- Keep: Crop to the exact review control while captions explain its role.
- Try: Follow the first issue through diff, check and resulting behavior.
- Try: For Tin, return to the original campaign after showing parallel tasks and approve its final artifact.
- Avoid: Using a different completed task as an unexplained payoff for the task just started.
- Still open: Isolation, actual test/merge execution, remote connections, product claims and audio qualities remain unverified.
