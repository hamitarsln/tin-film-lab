# 360 · Skillsync | Convert your GitHub into a live resume

**Explains well:** A request for a resume motivates the profile conversion and sent-message payoff.

**Still unclear:** The conversion and result pass too quickly to explain how the listed skills relate to the original GitHub work.

## Lessons

- Keep: Give a product action a clear trigger through an incoming request.
- Try: For a portfolio launch, hold one repository beside its extracted skill for two seconds before showing the final profile.
- Try: Try a matched return to the opening building or desk after the message sends, using one restrained brand detail in that same environment.
- Avoid: Avoid changing account evidence or cropping away the source behind a skill claim.
- Still open: Footage origin, skills accuracy, live updates, sent content and all audio remain unverified.
