## Lessons

- Keep: Keep input, labels and layout fixed while the two results arrive at different times.
- Try: Compare one Tin report task using equal panels, the same source data and an elapsed timer, with a named completion criterion.
- Try: At each completion, hold a readable output excerpt and list the same two checked functions so speed does not stand in for quality.
- Avoid: Avoid presenting source video time as a general performance benchmark.
- Still open: Run conditions, edit speed, representative performance, game correctness and all audio remain unverified.
