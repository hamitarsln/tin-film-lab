## Lessons

- Keep: Use a simple conveyor-and-box diagram to define the repetitive task.
- Try: Show robot setup and one complete packing cycle at the same existing workstation.
- Try: For Tin, add automation to the customer’s visible existing board and complete one task there.
- Avoid: Using unrelated industrial footage as evidence of a no-redesign deployment.
- Still open: Actual installation, adaptation, autonomous cycle, performance claims and audio qualities remain unverified.
