## Lessons

- Keep: Use a dense example montage followed by clean white space to make an update reveal stand out.
- Try: For a Tin release, select three user tasks and label the old version, then compare one task directly with the new release.
- Try: Try the collage-to-small-stack transition using readable source labels, followed by a single concrete improvement instead of rotating praise.
- Avoid: Avoid treating prior-version testimonials as proof of a new version or leaving the actual improvement unnamed.
- Still open: Example provenance, quote accuracy, model improvement, comparative claims and all sound remain unverified.
