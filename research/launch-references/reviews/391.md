## Lessons

- Keep: Show a complete request, review and running result before expanding into other capabilities.
- Try: For Tin, retain the same task name from request through review and final output.
- Try: End a recurring-task setup with one example run and its delivered result.
- Avoid: Avoid letting configuration controls stand in for the outcomes of later features.
- Still open: Actual timing, code quality, full design parity, migration completion, recurring/cloud execution and heard audio properties remain unverified.
