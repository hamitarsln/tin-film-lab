# 394 · Martini | Martini brings film sets to AI video production

**Product from the film:** Martini presents a way to explore an AI-video scene as a film set and create different framings of the same characters and room.

**Explains well:** The Step into Set menu leads to visibly different views of the same library-like room and two characters.

**Still unclear:** The rapid sequence does not explain which controls change the camera, how new shots are generated or how much continuity is preserved.

## Lessons

- Keep: Use one named action to open a new workspace while preserving the same recognizable asset.
- Try: For Tin, show one control change and its direct output before a fast result grid.
- Try: Keep a small original-frame reference visible while showing alternate outputs.
- Avoid: Avoid compressing the defining interaction so far that navigation and generated results become indistinguishable.
- Still open: Scene reconstruction, camera-control mapping, generation time, fine continuity and all heard audio properties remain unverified.
