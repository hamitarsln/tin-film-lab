## Lessons

- Keep: Combine several data attributes into one understandable example.
- Try: Open one result and show how its fields match the query.
- Try: For Tin, build a reference query one filter at a time and inspect a result.
- Avoid: Replacing the actual data output with generic data imagery.
- Still open: Scale, search behavior, dataset release, source rights and sound remain unverified.
