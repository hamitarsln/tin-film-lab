## Lessons

- Keep: Show the exact installation command before the announcement.
- Try: For a Tin developer skill, follow installation with a campaign-creation prompt and resulting draft.
- Try: Make a second version with the command held beside the result, so viewers can connect setup to benefit.
- Avoid: Relying on compatibility logos to explain the use case.
- Still open: Actual audio, subsecond transition details and a working agent-to-video result remain unverified.
