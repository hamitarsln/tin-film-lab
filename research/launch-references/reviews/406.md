## Lessons

- Keep: Keep the same named example through creation, use and publication.
- Try: Try a Tin interview that shows the actual campaign brief within the first 15 seconds.
- Try: Try a build demo that holds one user input and useful app response, then labels web published versus store submission states.
- Avoid: Avoid showing a publication-start button as if distribution is complete.
- Still open: Audio delivery, unshown build interval, native behavior and store submission remain unverified.
