## Lessons

- Keep: Show the human physical steps behind an AI-managed workflow.
- Try: For a Tin case study, trace one request through agent messages, human approval and delivered output, with matching assets.
- Try: Use two named desk cards to explain worker and reviewer roles, then show a dated outcome chart for the revised setup.
- Avoid: Using money props as the only visual support for a business-result claim.
- Still open: Actual listening, reenactment scope, financial records and causal effect of each architecture change remain unverified.
