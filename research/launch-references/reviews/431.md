# 431 · Oracle | Introducing Oracle: Like Post, Buy Coin

**Product from the film:** Oracle presents a social agent that turns liking a token post into a purchase, with a larger purchase tied to a comment.

**Explains well:** The like-to-purchase example is stated in words and shown through a post and phone notification.

**Still unclear:** The film skips how an ordinary like is authorized as a purchase, how the amount is set, and how the user can stop it.

## Lessons

- Keep: State an action in large text and immediately pair it with a readable outcome.
- Try: For Tin, show a user approving one post and the scheduled-state notification, with the approval setting visible first.
- Try: Compare the effects-heavy explanation with the same character guiding one calm, continuous UI sequence.
- Avoid: Presenting an everyday social gesture as a purchase trigger without showing user control.
- Still open: Authorization, limits, execution and actual sound remain unverified.
