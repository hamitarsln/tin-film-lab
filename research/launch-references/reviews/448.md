# 448 · ChatGPT Atlas | Meet our new browser—ChatGPT Atlas

**Product from the film:** ChatGPT Atlas is a browser with page-aware assistance, inline writing help, browsing memory and an agent that prepares shopping carts.

**Explains well:** The shopping example shows a request, a Continue confirmation, visible browsing steps and a cart ready for checkout.

**Still unclear:** The email-shortening example ends before a clearly readable revised draft, so its before-and-after is incomplete.

## Lessons

- Keep: Show a user confirmation before the agent acts, then visible action steps and a result.
- Try: Make the shortened email result readable beside its original.
- Try: For Tin, show proposed action, confirmation, execution steps and reviewable campaign output.
- Avoid: Treating a cart-ready state as a completed purchase.
- Still open: Answer accuracy, memory behavior, execution reliability and sound remain unverified.
