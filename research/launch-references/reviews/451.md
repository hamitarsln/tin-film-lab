# 451 · Strawberry | Strawberry Raises $6M to Run AI Agents in the Browser

**Product from the film:** Strawberry is a browser with named AI companions that work inside tabs for outreach, recruiting and invoices.

**Explains well:** Each task has a distinct character and prompt; the recruiting example ends in a candidate table and a request for human input.

**Still unclear:** The outreach example shows prepared messages and Send buttons without a clear delivery result or approval boundary.

## Lessons

- Keep: Tie a named role to its prompt, pointer and output.
- Try: Show the outreach approval and final status.
- Try: For Tin, let a campaign agent ask one clear question before continuing to a readable output.
- Avoid: Using a Send button alone as proof of delivery.
- Still open: Live task success, sending permissions, invoice accuracy and sound remain unverified.
