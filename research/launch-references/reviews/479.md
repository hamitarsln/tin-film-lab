# 479 · Cluely | Cluely Adds Live Web Search to Meetings

**Product from the film:** Cluely frames live web search in meetings as a fortune teller receiving timely information.

**Explains well:** Search panels appear beside each visitor before the fortune teller responds, linking incoming context to an answer.

**Still unclear:** The joke panels do not show reliable sources or the real search controls, so the actual meeting workflow remains unclear.

## Lessons

- Keep: Give background research a stable visible panel beside the ongoing conversation.
- Try: For Tin, show a source panel beside a live campaign discussion and carry one fact into the draft.
- Try: Replace one red joke warning with a real result title, source and open action.
- Avoid: Letting comic certainty stand in for a readable source and actual control.
- Still open: Real interface fidelity, source reliability, search timing and audio remain unverified.
