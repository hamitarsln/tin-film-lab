# 484 · Comet | Comet is here: A web browser built for today’s internet

**Product from the film:** Comet is a browser assistant that acts on a map, explains a Slack thread and retrieves a requested video moment.

**Explains well:** The map example shows a request followed by a route on the same page.

**Still unclear:** The voice example hides the request in an almost empty screen, so its purpose is weak without sound or captions.

## Lessons

- Keep: Keep the source page visible beside the assistant request and result.
- Try: For Tin, show the campaign page beside a request and then the specific changed campaign field.
- Try: Compare the voice example with a captioned request and a shorter retrieved clip marked with its timestamp.
- Avoid: Leaving an important request invisible while the screen holds a faint voice ring.
- Still open: Exact route quality, retrieval precision, voice timing and sound design remain unverified.
