## Lessons

- Keep: Pair the product promise with a visible integration change.
- Try: For Tin, show one API setting and the exact campaign workflow it enables.
- Try: Demonstrate retrieval of an early detail after a long conversation, with clearly scoped baseline numbers.
- Avoid: Using a tiny example as apparent proof of a very large scale claim.
- Still open: Benchmark provenance, scale, latency, cost, code execution and audio remain unverified.
