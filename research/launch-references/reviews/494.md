## Lessons

- Keep: Use the same composition across styles to show range clearly.
- Try: For Tin, keep one campaign message and layout fixed while comparing several approved visual styles.
- Try: Add a brief character input and style choice before returning to the finished spokesperson.
- Avoid: Treating a finished-output reel as an explanation of creation controls.
- Still open: Input method, output provenance, time savings, lip sync and actual voice remain unverified.
