# 498 · Figma | Introducing Figma Sites: Designs to the Web

**Product from the film:** Figma Sites turns designs into responsive websites with interactions, generated components and publishing.

**Explains well:** The same layouts are shown at several widths, and an analog clock moves from prompt to code preview to the page.

**Still unclear:** Publishing is presented as a final button without a visible live URL, while the many interaction controls pass too quickly for their setup to be clear.

## Lessons

- Keep: Show a custom component in the final page after generating it.
- Try: For Tin, carry a requested interactive campaign element from prompt to preview to the published landing page.
- Try: Add a live-page confirmation after Publish site and compare whether the workflow feels complete.
- Avoid: Stopping a publishing story at the button without showing the published result.
- Still open: Live publishing, browser behavior, component correctness, exact animation timing and audio remain unverified.
