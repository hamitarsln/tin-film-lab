# 500 · Gamma | Introducing AI Image Editing with Animation in Gamma

**Explains well:** The balloon image stays in the same page while requests change afternoon lighting and add balloons, making each edit easy to see.

**Still unclear:** Animation is introduced through a button and brief results, but duration, motion control and export behavior are not explained.

## Lessons

- Keep: Demonstrate sequential edits on the same image within its final layout.
- Try: For Tin, change time of day and product placement on one ad image while keeping the ad frame fixed.
- Try: Add a fixed before/after animation preview with a duration control to the underwater example.
- Avoid: Replacing a clear edit chain with a rapid result gallery before animation behavior is understood.
- Still open: Animation quality, duration controls, export behavior, generation time and audio remain unverified.
