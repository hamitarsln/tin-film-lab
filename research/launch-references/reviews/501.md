# 501 · Lovable | Lovable 2.0: multiplayer vibe coding

**Product from the film:** Lovable builds websites and apps from prompts, with collaboration, visual editing, custom domains and code access.

**Explains well:** The shopping-site example shows a first prompt and a specific follow-up that adds a profile sidebar.

**Still unclear:** The film switches projects between creation, collaboration and publishing, so viewers do not see one app completed through all stages.

## Lessons

- Keep: Show one specific follow-up edit after the first generated result.
- Try: For Tin, generate one campaign page, then add a clearly requested signup panel before inviting a teammate.
- Try: Carry the same shopping project through collaboration and publishing to reduce example switching.
- Avoid: Combining several projects into an apparently continuous end-to-end workflow.
- Still open: Build quality, real collaboration, publishing state, performance claims and audio remain unverified.
